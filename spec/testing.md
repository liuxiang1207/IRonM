## [2026-10-20]

对应: spec.md `[2026-10-20]`

**当日变更概览**: 新增"模块依赖方向"约束的验证清单；新增时间来源、标识、配置、结构化日志的验证清单；新增记录、缺失值、指标结果契约与 Schema 导出的验证清单；补充可选项省略与"围度"记录的验证项；新增 Agent 输出、字段归属、快照、计划版本、模型调用记录的验证清单。

### 1. 工程约束：模块依赖方向

- [x] 当前代码运行项目标准检查，依赖方向一项通过
- [x] 在安全规则模块中临时加入对任一其他业务模块（如 Agent 层）的引用 → 标准检查失败，输出中同时出现调用方与被调用方名称
- [x] 在下层模块（如计算层）中临时引用上层模块（如编排层）→ 标准检查失败
- [x] 在 Agent 或 Skill 层中临时直接引用数据存储模块 → 标准检查失败
- [x] 安全规则模块引用共享契约 → 标准检查通过（允许的依赖不被误报）
- [x] 新建一个未登记分层的业务模块 → 标准检查失败，并提示该模块未登记
- [x] 提交前检查与持续集成对同一违规给出相同的失败结果

### 2. 工程基础：时间、标识、配置与日志

- [x] 固定时间后连续多次读取当前时间，结果相同；向前拨动 3 天后读取，恰好晚 3 天
- [x] 读取到的当前时间带时区且为 UTC；用不带时区的时间设定固定时刻 → 报错
- [x] 默认方式连续生成 1 万个标识，没有重复
- [x] 同一种子两次生成的标识序列完全相同；不同种子生成的序列不同
- [x] 不设任何 `IRONM_` 变量 → 环境为 `dev`、日志级别为 `info`
- [x] 设置 `IRONM_ENV=staging` 或未知变量 `IRONM_FOO=1` → 启动失败，错误信息含该变量名
- [x] 写一条日志 → 输出为一行可解析的结构化记录，时间等于当前固定时刻，含级别、来源、事件名和字段
- [x] 日志事件名含空格或中文等自由文本 → 报错；附加字段用非允许的名字（如体重）→ 报错
- [x] 记录一个消息中含体重数字的异常 → 日志里只有异常类型，不出现该数字
- [x] 日志级别设为 `warning` 时，`info` 日志不输出
- [x] 固定时间与种子下同一流程跑两次，标识与日志输出逐字一致

### 3. 数据契约：记录、缺失值与指标结果

- [x] 七种记录类型各一条合法样例都能通过校验，序列化后再解析与原记录相等
- [x] 类型为称重、内容却是饮食字段 → 拒绝
- [x] 发生时间晚于记录时间、时间不带时区、出现未定义字段 → 分别拒绝
- [x] 来源为设备但没有数据流 → 拒绝；来源为用户时不要求数据流
- [x] 体重 15 千克或 500 千克、数值为 NaN、体重写成文本 "80" → 分别拒绝
- [x] 更正记录指向原记录，可以通过校验
- [x] 可空字段用"未知"表示能通过；缺少原因的"未知"被拒绝；在该填数值的地方给空值 → 拒绝
- [x] 对"未知"做加法或放进条件判断 → 报错
- [x] 合法的指标结果（正常、数据不足、数值未知）都能通过校验
- [x] 正常状态但数值未知、数值未知却带可信范围、可信范围不含数值、下限大于上限、数据不足却没写还差什么 → 分别拒绝
- [x] 导出的 Schema 文件存在于版本库，内容与当前契约一致；改动契约而不重新导出 → 标准检查失败
- [x] 饮食记录不填热量 → 热量为"未知（没记录）"，不是 0 或空值
- [x] "围度"记录只填腰围的合法样例通过，序列化后再解析相等；缺少腰围、腰围超出物理可能范围、出现未定义的部位 → 分别拒绝

### 4. 数据契约：Agent 输出、字段归属、快照、计划版本与模型调用

- [x] 每个计划字段都恰好登记了一个负责 Agent，且负责者都是提案型 Agent
- [x] 营养师修改每日热量目标的提案通过；营养师修改每周有氧分钟（归训练规划师）→ 拒绝，错误信息指出越权的字段和 Agent
- [x] 营养师产出判定、证据审查官产出提案 → 拒绝；任一 Agent 给出"无意见" → 通过
- [x] 提案缺预期效果、回退条件或复核日期之一 → 分别拒绝；新值与原值相同 → 拒绝；同一输出里两条提案改同一字段 → 拒绝
- [x] 拒绝或警告类判定缺理由代码 → 拒绝；放行判定可不带理由代码
- [x] 合法快照通过；修改快照的任一字段（含档案、精度表）→ 报错；精度表缺一个领域、同名指标重复 → 拒绝
- [x] 第 1 版计划带上一版本号、第 3 版的上一版本号为 3、差异中的新值与字段取值不一致 → 分别拒绝
- [x] 成功的模型调用记录通过；出错的调用不带错误类型 → 拒绝；用量写"未知"可以通过；记录没有存放提示或回答原文的字段
- [x] 新增契约的 Schema 文件已导出并与契约一致
